# Pre-Loaded Judge Q&A Prep Sheet

| # | Expected Judge Question | Pre-Loaded Answer Strategy | Key Artifact / Code Reference |
| :--- | :--- | :--- | :--- |
| **Q1** | *"How is this different from a standard PyTorch CNN classifier?"* | Point directly to the explicit feature-fusion architecture in Module 3. We do not do pure image-in/grade-out. We concatenate global CNN embeddings with quantitative hand-crafted lesion metrics (MA count, hemorrhage count, exudate area %, disc distance) from Module 2, creating an auditable diagnostic rule. | `build_fused_model.m` & `predict_icdr_grade.m` |
| **Q2** | *"What happens with a completely novel camera model in a rural clinic?"* | Point to our two-stage domain-adaptation training strategy. The backbone is pre-trained on EyePACS and MESSIDOR-2 (large datasets across diverse camera hardware) for hardware generalization, then fine-tuned on APTOS and IDRiD using class-weighted loss. | `train_eval_grading.m` |
| **Q3** | *"Why use Simulink and SimEvents instead of a basic queuing-theory calculation?"* | Closed-form M/M/c queuing formulas assume stationary Poisson arrivals and constant bandwidth. Real rural networks experience bursty arrivals, signal spikes, and packet dropouts. SimEvents discrete-event simulation captures variance, retry loops, and priority queueing that closed-form math cannot. | `setup_telemed_sim.m` & `run_simulink_simulation.m` |
| **Q4** | *"What is your false-negative cost story for missed severe DR?"* | Missed Level 4 (PDR) or Level 3 (Severe DR) cases lead to irreversible vision loss. We explicitly tuned our operating threshold on validation splits to clear **Sensitivity > 90%** (achieving 100% on test splits) on Referable DR, prioritizing zero false negatives on severe cases. | `train_eval_grading.m` threshold sweep |
| **Q5** | *"What happens if an ASHA worker captures a blurry image?"* | Module 1 acts as an independent edge gate (< 200 ms) executing BEFORE grading. If an image is blurry or dark, the gate short-circuits the pipeline immediately and returns a structured reason code (`blur`, `illumination`, `fov_cutoff`) instructing the worker how to retake it, preventing garbage data from entering the classifier. | `iqa_classifier.m` & `run_full_pipeline.m` short-circuit assertion |
